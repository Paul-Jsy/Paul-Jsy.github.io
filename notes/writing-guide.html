配置（简要）

下面示例展示如何在主题配置中启用或禁用部分功能（0. theme.ts 示例）：

import { hopeTheme } from 'vuepress-theme-hope'

export default hopeTheme({
    // ... 其他配置
    mdEnhance: {
        chart: true,
        echarts: true,
        mermaid: true,
        plantuml: true,
        // 启用属性、流程图、数学公式等
        attrs: true,
        flowchart: true,
        katex: true,
        presentation: true,
        demo: true,
        playground: true,
    },
})

示例中若某些块不渲染，请检查 mdEnhance（或 markdown）配置是否开启对应功能。
